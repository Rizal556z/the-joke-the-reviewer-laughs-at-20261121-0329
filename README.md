A one-line joke about working beside AI coding agents, for the make.fun
bounty [“The joke the reviewer laughs at”](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

## Run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, one line, 151 characters
including the trailing newline). Pure Python 3.13 standard library, no
network access, no dependencies.

## The joke

> My AI pair programmer writes the code, reviews its own code, approves its
> own pull request — and still asks me to explain what it just did in standup.
